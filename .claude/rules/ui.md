# Правила вёрстки

Дизайн-система «код как клавиатура» описана в `docs/DESIGN.md`. Расхождения с ним считаются багом, а не вкусовщиной.

- Цвета, отступы, радиусы и шрифты берутся из `lib/core/theme/` (`AppColors`, `GameColors`, `AppSpacing`, `AppTypography`). Новый токен добавляйте туда и в таблицу в `docs/DESIGN.md`.
- Нажимаемое оформлено клавишей `Keycap`, код лежит на `CodeBoard`. Без градиентов, капс-заголовков и эмодзи. Единственная тень — ребро клавиши.
- Жёлтый `Python Yellow` — только награды и только с тёмным текстом или на тёмной доске.
- Касание не меньше 48 px, клавиши ответов 56–64 px.
- У каждой клавиши и строки кода есть `Semantics`-подпись. У drag & drop есть альтернатива без перетаскивания («Поднять выше / Опустить ниже»).
- Анимации отключаются при `MediaQuery.disableAnimations` («уменьшить движение»).
- Режим «На время» всегда в `AppTheme.timed`, какая бы тема ни была в системе.
- Никакой горизонтальной прокрутки страницы и обрезанного текста. Проверяйте ширину 320 dp, масштаб шрифта 200 %, светлую и тёмную темы.
- UI не меняет состояние напрямую: только через контроллеры и провайдеры Riverpod (ADR-5).
- Новый экран начинайте со спеки по шаблону `.claude/templates/ux-spec.md`: все состояния (загрузка, пусто, ошибка, нет жизней, офлайн) описываются до вёрстки.
